# Fonts shipped with `@openref/theme`

These files are not the work of this project. They are third party typefaces, vendored under
zone 4 of SPEC 0, and they ship inside the published package.

**Every file here is a subset of the original.** Each face was reduced to the latin and
latin-ext ranges, its TrueType hinting instructions were dropped, and it was converted to
woff2. Outlines, metrics and OpenType layout features are unchanged. A subset is a derivative
work, so each subset is under the same licence as the family it came from.

The licence text of each family sits beside these files, taken verbatim from that family's own
repository and never rewritten. `manifest.json` records the exact source of every file, the
date it was retrieved and the digest of the bytes as they are here.
